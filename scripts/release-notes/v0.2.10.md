# SpellCheck v0.2.10

Completing the removal of replacement messaging, based on your decision.

## Changed

- **No more "could not replace" messages — at all**: previously the menu bar could show an explanation when the write-back could not be carried out (e.g. "the selection is no longer intact" or "the document changed"). That text is now completely gone — no text, no explanation, no popup. If nothing happened, you see it on screen, and the corrected text is on the clipboard.
- **The menu-bar icon is now just an icon**: the old ⏳/✓/✗ status logic was dead code in the installed app (the icon always replaced it) and has now been removed entirely. The icon never changes during a correction. The cursor spinner is the only indicator that the app is working.
- Real API, configuration and permission errors still appear as clear alerts — only the feedback about the document write-back itself has been removed.

## Pre-paste safety is unchanged

The app still checks that the selection and target document are unchanged before pasting — otherwise nothing is written (and never to the wrong place). The paste command is issued exactly once.

## Verification that remains (your test on a real Mac)

Automated tests (Core 76, Engine 49, App tests on macOS CI) and build/CI are green. Check that corrections work as before in Notion and TextEdit, and that you never see replacement-failure text in the menu bar anymore.

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app from v0.2.1+.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
