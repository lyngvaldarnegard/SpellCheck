# SpellCheck v1.1.1

A smarter starting order for the model whitelist.

## Changed

- **New whitelisted models are tried first, once**: models you add to the whitelist that have no measured response times of their own are now served FIRST (in your whitelist order) — ahead of the proven-fast ones — so each earns a real measured number on its first request. From then on, the data-driven ranking takes over: fastest measured model first, fall-through on failures as before. Previously, unmeasured models inherited the all-models average and could sit mid-list indefinitely without ever being tried.
- The progress ring's estimate for an unmeasured model still uses the all-models average; the whitelist ranking is what changed.

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
