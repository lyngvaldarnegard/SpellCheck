# SpellCheck v1.1.8

One focused fix: the app could report "No text found" while text was clearly selected.

## Fixed

- **Browser selections are now always captured.** The last-resort clipboard grab (copy the selection with ⌘C, then read it back) was gated on the same 3-second budget as the Accessibility searches before it. On large web pages (Safari, Chromium) those searches can spend the entire budget walking the accessibility tree without finding a text element, so the clipboard grab never ran and the app reported "No text found" even with text selected. The clipboard grab now always runs, independent of that budget — it is the only capture layer that works reliably on browser selections.
- **⌘C race hardened:** the grab now polls the pasteboard for up to 600 ms instead of a single read after a fixed 250 ms wait, so a slow target app can no longer make the selection look empty.

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
