# SpellCheck v0.2.9

One change, based on your decision — the workflow is otherwise unchanged.

## Changed

- **No verification after pasting anymore — the text is pasted and done**: after the AI has answered, the corrected text is pasted straight into the selection without the app waiting or reading the document back afterwards. This saves roughly 0.5–1 second per correction, and you are rid of the "could not verify" messages for good. You see the result on screen yourself — that is the verification.

## Pre-paste safety kept

The following checks were NOT removed — they ensure text is never written to the wrong place:

- The app the text came from is re-activated, and the selection must still be the same one as when you started.
- If the document changed in the meantime (you edited or moved away), the write-back is aborted and nothing is written.
- The paste command is issued exactly once — never automatically restarted or retried.

## Verification that remains (your test on a real Mac)

Automated tests (Core 76, Engine 49, App tests on macOS CI) and build/CI are green. Check that corrections now feel faster, and that text still lands correctly in Notion and TextEdit. Note one honest consequence of this change: if a paste command were to silently fail in some app case, the menu bar still shows ✓ — the corrected text is then on the clipboard, so ⌘V fixes it manually.

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app from v0.2.1+.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
