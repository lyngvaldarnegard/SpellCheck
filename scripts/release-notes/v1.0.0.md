# SpellCheck v1.0.0

The first full-numbered release. The core workflow is unchanged: select text → ⌥L → choose a prompt → the text is replaced in the original app.

## New

- **New default prompt list (19 prompts)**: your saved prompt collection is now the shipped default list — including a new **Humanize** prompt (the careful human-voice editor), utility prompts (Convert to Markdown, Friendly Tone, Decline Request by Email, 10 Rewrites, TLDR, Synonyms, Active Voice, Make Persuasive, Sales Copy) and four translation prompts (English, Esperanto, Norwegian Bokmål, Norwegian Nynorsk) at the bottom of the list. The Allvit, Napoloen and Juss prompts were left out by choice.
- **Updates never touch your own prompts**: when you install v1.0.0, your existing prompt list stays exactly as it is — same order, same text. Default prompts whose titles you don't already have are **imported at the bottom** of your list (matched by exact title; your own same-titled prompts always win). This happens once — if you delete an imported prompt afterwards, it stays deleted.
- **Autosave**: every change in Settings and the Prompt Editor persists automatically — editing a title or prompt text, changing icons, adding, deleting and drag-to-reorder. ⌘S and the Save button still save immediately, and the Saved indicator still confirms.
- **Circular progress ring** (replacing the old spinner): a clean ring appears near the cursor while the AI is working. It fills from the top clockwise over the **estimated** response time; if the request takes longer, the ring resets and sweeps again until the text is replaced; it then disappears.
- **Learned response-time estimates**: the app measures how long each request actually takes and estimates the next one as rate-per-character × text length, using the **inter-quartile mean** (outliers like network stalls are trimmed). Estimates are per model, fall back to the all-models average for brand-new models, and default to 1 second per ring revolution only when nothing has been measured yet. All of this runs in the background with no effect on response time, and only numbers are stored (no text, prompts or keys).
- **Response Times section in Settings**: shows every tracked model with its sample count, median, inter-quartile mean and inter-quartile range (seconds per 1000 characters).

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app from v0.2.1+.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
