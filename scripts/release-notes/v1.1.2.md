# SpellCheck v1.1.2

One small change to the progress ring.

## Changed

- **No more clamping on the ring's rotation time**: the ring now uses the raw learned estimate, however small or large — previously estimates were limited to between 0.5 and 120 seconds per rotation. If your data says a request should take 0.2 seconds, the ring does a 0.2-second revolution; if it says 300, it does 300. Everything else is unchanged: the ring still fills from the top clockwise, wraps and re-sweeps when the request outlives the estimate, and disappears the moment the text is replaced.

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
