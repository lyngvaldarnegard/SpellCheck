# SpellCheck v1.1.6

Fixes for the Response Times box plots after real-world feedback.

## Fixed

- **The legend no longer overlaps the last plot row** — the plot list now has an explicit height, so the explanation text sits cleanly below it.
- **All five values are now labelled**: min, Q1, median, Q3 and max each get their number under the plot. Labels that would collide are staggered onto a second line instead of being dropped — so Q1 and Q3 are always shown, even when they sit close to the median.
- **The IQM marker is now red** (with its value printed in red next to it), so it clearly contrasts with the green box and median details.

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
