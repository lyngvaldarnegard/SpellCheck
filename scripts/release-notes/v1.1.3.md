# SpellCheck v1.1.3

Three improvements for the model pickers and whitelist.

## Changed

- **Whitelist checkboxes now sit to the LEFT of the model names** (standard macOS checkbox layout) instead of switches on the far right edge — it was hard to tell which switch belonged to which model.
- **"latest" models are sorted to the top of every fetched model list** (Model, Backup model and the whitelist): the current-generation variant of each family — mistral, magistral, voxtral, codestral, ... — is listed first, alphabetically within the group, followed by everything else. No more scrolling past dozens of dated model IDs to find the ones you want.
- **The whitelist list is collapsed by default**: it shows only the models you have actually whitelisted. A "Show all models" button expands the full fetched list when you want to check more; "Show whitelisted only" collapses it again.

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
