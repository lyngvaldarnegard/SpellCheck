# SpellCheck v1.1.5

Refinements to the Response Times box plots.

## Changed

- **The IQM marker is now clearly visible**: a larger green dot with a contrasting ring, so it no longer disappears inside the box — and its value is printed right next to it in green.
- **Numeric labels on every box plot**: the min, Q1, median, Q3 and max values are printed in small text under each plot at their axis positions (labels that would overlap are skipped, so the numbers always stay readable). Together with the IQM value next to the dot, every element of the plot is now marked with its number.

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
