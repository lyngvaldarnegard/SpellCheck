# SpellCheck v1.1.10

One focused fix: the false "No text found" in Notion — and any other app that exposes no focused Accessibility element.

## Fixed

- **The clipboard fallback is now truly unconditional.** When the target app (Electron apps like Notion) exposes no focused Accessibility element at all, the grab used to abort with "No text found" before the clipboard fallback could even run. Now the Accessibility layers are skipped and the selection is captured via ⌘C instead. The correction is pasted back over the still-selected text, verified only as far as such apps allow (the original app must still be frontmost).
- **Longer ⌘C window:** the fallback now waits up to ~1.5 s for the target app to service ⌘C (previously ~600 ms). A heavy Notion page can take longer than the old window, which made the grab report "No text found" while the copy was still in flight. It still returns as soon as the copy lands.
- **Better diagnostics:** every failing capture branch now logs a distinct message (Console.app → subsystem "SpellCheck", category "ax"), so any future occurrence is identifiable at a glance.

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
