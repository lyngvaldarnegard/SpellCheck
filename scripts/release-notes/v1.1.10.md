# SpellCheck v1.1.10

One focused fix: the text-capture fallback that reads your selection via the clipboard is now robust in Electron apps such as Notion.

## Fixed

- **"No text found" in Notion and other Electron apps (issue #19).** When none of the accessibility layers could read the selection, the clipboard fallback gave the target app only ~600 ms to react to a single synthetic ⌘C — too short on large Notion pages, and Electron web views can drop synthetic keyboard events entirely. The fallback now:
  - waits up to ~2.5 s for the clipboard,
  - presses the app's Edit > Copy menu item via Accessibility when nothing landed after ~600 ms — Electron apps keep a native menu bar, so this path works even when the web view ignores synthetic keys,
  - re-posts ⌘C once at ~1 s as a last resort,
  - logs which measure ran to Console.app (subsystem `SpellCheck`, category `ax`) for troubleshooting.

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
