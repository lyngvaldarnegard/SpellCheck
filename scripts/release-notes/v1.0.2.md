# SpellCheck v1.0.2

A small refinement of the Response Times statistics, plus the ring-direction fix from v1.0.1.

## Changed

- **Response Times are now shown in seconds per 100 tokens** (estimated at 4 characters per token, the standard approximation) instead of seconds per 1000 characters — the same learned data, in the units the API actually processes and bills. The median, inter-quartile mean and inter-quartile range in Settings → Response Times all use the new unit. The progress ring's speed is unaffected (its estimate is unit-independent).

## Included from v1.0.1

- The progress ring starts at 12 o'clock and fills clockwise (v1.0.0 started at the bottom by mistake).

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
