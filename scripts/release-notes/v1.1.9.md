# SpellCheck v1.1.9

One focused change: the Response Times section in Settings now matches the model whitelist.

## Changed

- **The statistics list follows the whitelist.** When a model whitelist is set, the Response Times section at the bottom of Settings lists only whitelisted models — a model removed from the whitelist can no longer serve requests, so it no longer appears there either. The two sections now agree.
- **With an empty whitelist, nothing changes:** every model that has recorded samples is listed, as before.
- **Your learned data is kept.** Removing a model from the whitelist hides its row but does not delete its stored samples — the per-model rolling window (at most 100 samples) caps the data anyway, and if you whitelist the model again, its learned history is back instantly.
- The shared box-plot axis adapts to the models shown, and the section legend notes the behavior.

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
