# SpellCheck v1.1.11

This update changes text capture to work with selected text only and adds more ways to copy a selection in apps such as Notion. The Notion capture issue still needs verification on a Mac (issue #19).

## Changed

- SpellCheck now requires selected text and no longer selects the sentence around the caret (issue #19).
- The clipboard fallback can also request a copy through the focused element's Accessibility action or send Command-C directly to the target process. If capture fails, the alert includes a diagnostic trace (issue #19).

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
