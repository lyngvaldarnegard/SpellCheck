# SpellCheck v0.2.6

New improvements based on your testing — the core workflow (select text → ⌥L → choose a prompt → the text is replaced) is unchanged.

## New

- **Shared prompt (Settings → "Shared Prompt")**: an editable common instruction sent with every request, before the selected prompt. The default text asks the model to deliver only the requested result, in the text's original language, without explanations, quotes or unsolicited Markdown. Changes are saved with Save/⌘S and survive restarts and updates.
- **Backup model (Settings → API)**: choose a primary model and an optional backup model. If a request fails temporarily (capacity, rate limit, server error, timeout) or returns a response the app cannot use, the same request is retried once on the backup model. The document write-back is never automatically repeated. If both fail, you get one clear error describing both attempts.
- **More tolerant response parsing**: some providers (e.g. GLM) return responses in a slightly different format, or `content: null`. Previously that gave "The data couldn't be read…". Such variations are now handled, and if the response genuinely cannot be interpreted, you get an actionable error message (and the backup model is tried if one is set). GLM compatibility is not verified against the provider here — feel free to test GLM 5.3 Flash and give feedback (issue #11).
- **Clicking outside closes the prompt picker**: the picker now behaves like a transient popup (like FixKey) — clicking anywhere outside closes it without running a prompt or touching the text. Search, scrolling, ↑/↓, Enter, Esc and the X button work as before.

## Changed

- **No more intrusive "could not replace text" popup**: write-back failures (including uncertain results) are now shown only as status in the menu bar. You can retry yourself; the corrected text is still on the clipboard. Real API, configuration and permission errors still appear as clear alerts.
- **The Ω icon is now the same size in both choices**: "Omega only" uses exactly the same Ω shape and scale as "Omega + checkmark" — only the checkmark is omitted. All four icons are still sharp vector images (PDF) that work in both light and dark menu bars. Previews are in `docs/icon-previews/` in the repo.
- **The "Loading…" window and the Space switch are gone**: the app no longer has a SwiftUI window that macOS could restore and bring forward (switching desktops) when the picker opened.
- **Open Settings/Prompt Editor windows are no longer raised** when you press ⌥L: while the picker is up, the app keeps the other windows behind other apps' windows. (Low-priority fix — please report if you still see it.)

## Verification that remains (your test on a real Mac)

Automated tests (Core 68, Engine 43) and the macOS build/CI have run green, but the following needs your confirmation: Notion and TextEdit end-to-end, keyboard/mouse/click-outside in the picker, GLM 5.3 Flash + fallback, prompts and ordering across restart/update, the icons on Retina, and that the window/Space behavior is gone. An end-to-end Sparkle update install has still not been observed — use "Check for Updates…" from an earlier version, or download the zip below.

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app from v0.2.1+.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
