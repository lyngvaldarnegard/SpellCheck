# SpellCheck v1.1.0

Automatic model choice from your own approved list, using the app's learned response-time data.

## New

- **Model whitelist (Settings → API)**: check the models you find acceptable — that is your quality/cost choice. The app then automatically serves every request from the **fastest whitelisted model**, based on the response times it has learned from your own usage. If that model fails temporarily (capacity, rate limit, server error, timeout, unusable response), the request falls through to the **next fastest**, and so on — one attempt per model, never a repeated paste. Authentication/configuration errors fail fast instead of burning the whole list. Leave the whitelist empty to keep using the Model field as before.
- **Outdated models are purged automatically**: when you fetch the model list, whitelisted models the provider no longer serves are removed from the whitelist, and their learned response-time samples are deleted — the app never calls or keeps data for retired models. (This is also why `-latest` model names work well: the whitelist tracks whatever the provider currently serves.)
- The ranking uses the same learned data as the progress ring and the Response Times section: per-model samples, inter-quartile mean, all-models fallback for models without samples, and your whitelist order when nothing has been measured yet.

## Notes

- The whitelist applies to the same provider/credentials as the Model field. The backup model setting is ignored while a whitelist is active (the whitelist supersedes it).
- Timing samples are attributed to the model that actually served the request, so rankings stay accurate even after fall-throughs.

## Verification that remains (your test on a real Mac)

Automated tests (Core 79, Engine 65, App tests on macOS CI) cover the ranking, fall-through, fail-fast, purge and persistence logic. Not verified interactively: the whitelist UI in Settings, and real fall-through behavior against your provider. Try it out and report anything off.

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
