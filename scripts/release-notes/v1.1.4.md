# SpellCheck v1.1.4

The Response Times section in Settings becomes a visual speed ranking (issue #18).

## Changed

- **Models are now ranked by IQM, fastest first** — the list in Settings → Response Times is sorted by each model's inter-quartile mean response time instead of alphabetically, so it reads directly as a ranking.
- **Box plots per model**: each row shows a horizontal box plot of that model's response-time distribution — the box spans Q1–Q3, the line marks the median, the whiskers span the observed min–max, and a green dot marks the IQM (the number the whitelist ranking and the progress ring actually use). All rows share one horizontal seconds axis, so the same seconds value sits at the same horizontal position in every row — ranges and medians are directly comparable across models at a glance.
- **Rolling 100-sample window**: each model keeps its most recent 100 samples (up from 20), dropping the oldest when new ones arrive — fresher statistics with a bigger pool for accurate quartiles.

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
