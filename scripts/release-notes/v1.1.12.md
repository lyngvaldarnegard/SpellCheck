# SpellCheck v1.1.12

Response Times now lists every whitelisted model, and saved settings take effect without a restart.

## Fixed

- **Response Times matches the model whitelist.** Every whitelisted model is listed, including models without a timing ("Not timed yet"). The order is the order they are tried: untimed models first, then fastest first. The list updates when you tick or untick a model.
- **Saved settings apply immediately.** Changes to the shared prompt, API key, base URL, model, backup model, whitelist or shortcut previously had no effect until the app was restarted.
- **Times use one format**, with your system's decimal separator.

## Changed

- **A failing whitelisted model no longer stops the request.** The next model is tried after any failure except cancellation, including errors such as "404 not found" or a rejected API key. An error is shown only if every whitelisted model fails.
- **Response Times shows which model answered last**, and why a model's latest try failed. This is kept until the app quits. Reopen Settings to refresh it.

## Installation

1. Run "Check for Updates…" in the menu-bar app. Or download `SpellCheck-macOS.zip`, unpack it and move SpellCheck.app to the Applications folder.
2. The app is ad-hoc signed: macOS may ask for confirmation (right-click → Open). After an update, you may need to remove and re-add SpellCheck under System Settings → Privacy & Security → Accessibility.
