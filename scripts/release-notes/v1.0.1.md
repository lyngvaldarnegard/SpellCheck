# SpellCheck v1.0.1

One fix for the new progress ring.

## Fixed

- **The progress ring now starts at the top**: in v1.0.0 the ring started at the 6 o'clock position and swept from there. It now starts at 12 o'clock and fills clockwise, as intended — and when the estimate is exceeded it resets to the top and sweeps again. Everything else about the ring (learned speed, wrapping, disappearing when the text is replaced) is unchanged.

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
