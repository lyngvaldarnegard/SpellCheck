# SpellCheck v1.1.7

One focused change to the Response Times box plots.

## Changed

- **The box plots no longer show the extreme endpoints**: the min–max whiskers and their labels are gone. The shared axis now spans only the smallest Q1 to the largest Q3 across all models, so a single slow outlier (say, one 36.9-second request) no longer stretches the axis and wastes half the plot. Each row shows the green Q1–Q3 box, the median line, the red IQM dot with its value, and numeric labels for Q1, median and Q3. The extremes are still part of the learned statistics — they are just not drawn.

## Installation

1. Download `SpellCheck-macOS.zip` and unpack it.
2. Move SpellCheck.app to the Applications folder. Alternatively: run "Check for Updates…" in the menu-bar app.
3. The app is ad-hoc signed: the first time, macOS may ask for confirmation — right-click → Open. After an update, Accessibility permission (System Settings → Privacy & Security → Accessibility) may need to be re-enabled.
